OUR LITTLE UNIVERSE — PURE HTML / CSS / JAVASCRIPT

No Python. No server. No build process. Just HTML, CSS and JavaScript.

PHOTO SETUP

Each main chapter holds 9 photos.
The separate Random Memory Vault holds 100 photos.

Folder structure:

photos/
├── beginning/       9 photos
├── medan/           9 photos
├── poland/          9 photos
├── engagement/      9 photos
├── memories/        9 photos
└── random/        100 photos

HOW TO NAME PHOTOS

Use three-digit numbers in each folder:

001.jpg
002.jpg
003.jpg
004.jpg
005.jpg
006.jpg
007.jpg
008.jpg
009.jpg

The numbering starts again inside every folder. It is completely fine to have
photos/beginning/001.jpg and photos/medan/001.jpg — they are different photos.

001.jpg → 009.jpg

001.jpg → 009.jpg

001.jpg → 009.jpg

Memories (Chapter 4):
001.jpg → 009.jpg

RANDOM MEMORY VAULT — 100 PHOTOS

Put the 100 special/random photos in:

photos/random/

Name them:
001.jpg → 100.jpg

The site chooses a random photo when the page first opens.
It does NOT jump to the bottom when this happens.

Every time “Give me a random memory” is pressed, another random photo is chosen.
It will never choose the same photo twice in a row.

ADDING OR REPLACING PHOTOS

For the five main chapters, keep exactly 9 numbered photos per folder.
If you replace a photo, keep its number.
If you want to change the order, simply rename the files.

For the random vault, use exactly 100 files numbered 001.jpg through 100.jpg.

SUGGESTED 9-PHOTO ORDER

001.jpg = opening / establishing photo
002.jpg = important moment
003.jpg = candid
004.jpg = close-up
005.jpg = funny or playful moment
006.jpg = place / travel photo
007.jpg = another candid
008.jpg = favourite photo
009.jpg = strongest photo to finish the chapter

These are only suggestions — choose the photos that feel right for your story.

IMPORTANT

Use .jpg files and three-digit filenames exactly as shown.
Do not put spaces in the filenames.

Then simply open index.html.
